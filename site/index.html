First run

  • Windows: SmartScreen may say "unknown publisher". Click More info, then Run anyway.
  • macOS: right-click the app, choose Open, then confirm. Allow Location so Wi-Fi names can show.
  • Linux: chmod +x Aura-OS-linux.AppImage, then run it.
  • The apps are not code-signed yet, so these warnings are expected. Intel Macs are not built yet.
